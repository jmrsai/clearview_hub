# Contributing to ClearView Hub

Thank you for your interest in contributing to ClearView Hub! We welcome contributions that help improve the vision therapy and clinical diagnostic tools we provide.

## Legal Notice

By contributing to this project, you agree that your contributions will be licensed under its Apache License 2.0.

## How to Contribute

### Reporting Bugs
- Use the GitHub issue tracker.
- Provide a clear description of the issue and steps to reproduce.
- Include information about your environment (OS, Flutter version, device).

### Suggesting Enhancements
- Open an issue with the "enhancement" label.
- Describe the feature and why it would be beneficial for users.

### Pull Requests
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/your-feature`).
3. Commit your changes with descriptive messages.
4. Push to your branch (`git push origin feature/your-feature`).
5. Open a Pull Request.

## Coding Standards
- Follow the official [Flutter style guide](https://flutter.dev/docs/development/style-guide).
- Ensure all new features include appropriate tests.
- Maintain military-grade security and HIPAA compliance standards in your code.

## Security
For security-related issues, please refer to our [Security Policy](SECURITY.md).
